# v2.0.0 — repeated-runs study, two user stories

Answers the reviewers' objection that a single generation per case cannot
separate a real effect from run-to-run variance.

## What is new

- **Repeated runs.** Ten independent generations per case instead of one.
- **A second user story.** MFA enrolment for online banking with dyslexia, added
  alongside the original password recovery for a health portal with ADHD. Its
  requirement documents follow story 1's structure section by section, so a
  difference between the stories cannot be attributed to prompt style.
- **60 artifacts**, up from 3, generated by `openai/gpt-5.6-terra` with no seed.
- **A 7-model judge panel**, one per laboratory, scoring both rubrics three
  times over: **2,457 judgements and 36,855 item scores**, up from 30 scores
  entered by hand.
- **Execution-based verification.** Every artifact is booted, probed, its client
  script checked in a real browser, walked through its own UI and photographed —
  509 screenshots. Non-working output is recorded, not rescued.
- **A complete analysis pipeline.** `analyse.py`, `report.py` and
  `build_workbook.py` regenerate every table from the raw records.
- **A human evaluation package.** The six best artifacts, source code plus a
  Cloudflare Containers deployment giving each expert a private instance.

## Findings

Detailed inclusivity guidance raises inclusivity scores in both stories
(*p* = 0.0001, Cliff's δ = −1.00; and *p* = 0.003, δ = −0.97 over working
artifacts) and does not measurably lower security scores (*p* = 0.077 and
*p* = 0.740). Naming the condition alone does nothing.

The cost appears elsewhere: in story 2, case 3 converged 4/10 against 10/10 and
10/10, and only 6/10 of its artifacts had a working client script
(χ² = 9.23, *p* = 0.0099). Asking for accessibility made the model markedly more
likely to ship something broken.

## Compatibility

The 2025 single-run collection is retained **unchanged** at
`final_evaluations/results/`, with its artifacts in `workspace/`. It is a
separate experiment, not a superseded version — different generator, different
panel, different aggregation. Do not pool the two.
